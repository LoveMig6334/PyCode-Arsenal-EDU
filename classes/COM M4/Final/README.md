จงสร้างเกม ภารกิจพิชิตถ้ำมังกร (The Dragon's Cave)
คำชี้แจง: ให้นักเรียนเขียนเกมล่าสมบัติในถ้ำมังกร โดยใช้ความรู้เรื่อง List, While Loop และ if-else

รายละเอียด:
- การเล่น: * ในแต่ละชั้น ให้ผู้เล่นเลือกว่าจะไปทาง "ซ้าย (1)" หรือ "ขวา (2)"
    ระบบจะทำการสุ่มว่ามังกรอยู่ฝั่งไหน ถ้าผู้เล่นเลือก "ผิดฝั่ง" (เจอมังกร) เงินรางวัลในรอบนั้นจะเป็น 0 ทันที
    ผู้เล่นสามารถเลือก "ออกจากถ้ำ (3)" เพื่อเก็บเงินรางวัลทั้งหมดที่สะสมมาได้

- ระบบรางวัล: ชั้นที่ 1 เริ่มที่ 100G และในชั้นถัดๆ ไป รางวัลจะเพิ่มขึ้นเป็น 2 เท่า ของชั้นก่อนหน้าเสมอ

- การเก็บข้อมูล: * ใช้ List ชื่อ treasure_log เพื่อเก็บจำนวนเงินที่ได้รับในแต่ละชั้นที่ผ่านไปได้
    ใช้ List ชื่อ game_history เพื่อเก็บคะแนนรวม (Total Gold) ของการเล่นในแต่ละรอบ (ใช้บันทึกตอนจบเกม)

- การแสดงผล: * เมื่อจบเกม (ตายหรือออก) ให้แสดงจำนวนเงินรวมที่ได้ และ ลำดับรางวัลในแต่ละชั้น (เรียกข้อมูลจาก treasure_log)
    แสดง High Score(888) (คะแนนที่สูงที่สุดที่เคยทำได้) โดยเรียกจาก game_history ได้ตลอดเวลา
